# 第二轮优化记录（2026-11-01）

本轮保留前序优化与安全工具链升级，完成第二轮审计中列出的功能、性能和资源边界改进，未部署到正在运行的服务。

## 实现

1. 仪表盘直接使用服务端全范围任务摘要，近期清单只读取 5 条；地图处理进度查询直接筛选活动地图任务。
2. 预下载、扫描、地图任务仅在活动时以 3/3/2 秒轮询，空闲时降至 30 秒兜底；无准备能力的空列表停止查询。准备/扫描事件与节点重新上线刷新对应查询，保留无 jobs.read 账号所需的兜底。
3. 地图 API 按权限先过滤再以 created_at/id 游标分页；基础清单读取后先关闭 rows，每页用 6 组批量查询加载附属数据。200 张地图由约 1201 次 SQL 降至 7 次（不含主体授权），也不再占住列表连接等待第二个连接。前端最多读齐 50 页才进行搜索、重复检测和统计，超限明确提示。
4. 地图导入提示每账号最多 64 条、7 天 TTL，每分钟清理过期追踪；旧字符串格式一次迁移，读取及重复追踪不续期。终态/403/404 保持停止快速轮询和可确认提示，TTL 到期只清除浏览器记录。
5. 任务搜索增加 300 毫秒防抖，提交搜索后再重置游标，避免每个字符触发全范围统计。
6. Agent 固定 8 个 worker，总驻留 32 条，wire payload 预算 256 MiB；Control 在立即事务内限制每节点派发额度，Control 自身的安装清单协调任务不计入。通过 bounded_job_admission_v1/admission_retry/job_deferred 协商拥塞重派，旧端使用断线重放。取消及 ACK 不排入 worker 队列；已驻留任务退出前保留收到 ACK 的取消 tombstone，防止等待任务恢复执行。重复 ID 要求相同指纹，日志提供数量/字节占用而不记录正文。
7. 新迁移 024 为后台终态、传输终态、遗留密文清理和上传关联查询增加索引；每类任务每轮最多清理 500 条，保留原到期规则并排除取消待确认/终态待投影。审计及其他历史保留规则未改变。
8. 工具链安全升级已在上一轮完成；本轮 npm 仍为 0 漏洞、govulncheck 为 0 代码可达漏洞（保留未发现调用路径的依赖告警）。详见安全工具链升级记录。

- 前端 217 项单元测试、TypeScript/生产构建、132 项桌面/移动端模拟接口浏览器测试通过。
- 定向验证覆盖权限过滤前分页、单数据库连接完成地图批量读取、500 条分批回收、保留取消/投影屏障、节点派发上限及协调任务豁免、重复 ID、载荷预算、排队取消收到 ACK 后仍不执行、能力门控和跨节点拒绝。
